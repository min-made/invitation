# 크롤러 정책
#
# 이 파일은 "요청"이며 기술적 강제가 아닙니다. 무시하는 크롤러도 있습니다.
# 실제 차단이 아니라 "선의의 크롤러에게 의사를 전달"하는 수단입니다.
#
# ── 왜 검색엔진을 Disallow 하지 않는가 (중요) ──
# robots.txt 로 검색엔진을 막으면 페이지를 아예 읽지 못하고,
# 그러면 index.html 의 <meta name="robots" content="noindex"> 도 못 봅니다.
# 이 경우 외부에 링크가 노출되면 "내용 없는 URL"만 색인에 남을 수 있습니다.
#
# 확실히 색인에서 빼는 방법은 그 반대입니다 —
#   크롤링은 허용하고, meta noindex 로 "색인하지 말라"고 지시.
# 그래서 검색엔진은 Allow 로 두고 실제 배제는 meta 태그가 담당합니다.
# ════════════════════════════════════════════════════════════
